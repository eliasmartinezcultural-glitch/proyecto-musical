¿Qué vamos a trabajar?

La regla de esta sala

Todo explicado con palabras comunes, ejemplos visuales y oído. No hace falta leer música. Cada canción debe decir claramente qué hace la voz, el teclado y la guitarra.

Tu repertorio

Todavía no agregaste canciones. Empezá con un tema que estén practicando.

Canciones

Agregá canciones, pistas propias, letras y notas de ensayo.

FICHA DE CANCIÓN
El audio se usa desde este dispositivo. Para no llenar el almacenamiento del celular, las pistas grandes no se guardan dentro de la copia de seguridad automática.
Reproductor de ensayo

El cambio real de tonalidad sin alterar la velocidad se incorporará como módulo de audio en una etapa específica; no vamos a mostrar un control falso que no haga lo que promete.

Guía de acordes

Elegí un acorde y mirá una referencia sencilla. Son dibujos de orientación: pueden variar según la posición que use cada músico.

ACORDE SELECCIONADO

SOL

Para empezar, prueben este acorde despacio y escuchen si todas las notas suenan claras.

Teclado: buscá la nota con el mismo nombre. Para un acorde mayor se combinan tres notas; en la guía ampliada mostraremos las teclas exactas y una demostración de audio.

¿Cómo lo practicamos?

  1. Escuchá el acorde.
  2. Colocá los dedos o las manos.
  3. Tocá cada cuerda o tecla despacio.
  4. Repetilo varias veces hasta que salga cómodo.
  5. Unilo con el siguiente acorde de la canción.
